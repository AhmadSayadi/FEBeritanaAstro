# Beritana

**The Voice of Young Indonesian** - portal berita digital untuk generasi muda Indonesia.

## Apa itu Beritana?

Beritana adalah portal berita digital yang menyajikan informasi terkini, akurat, dan
terpercaya dengan gaya yang segar dan dekat dengan pembaca muda. Berdiri sejak **2016**,
Beritana mengangkat beragam kanal - nasional, politik, olahraga, teknologi, hiburan,
ekonomi, hingga gaya hidup.

## Yang disajikan

- **Berita teks** - artikel dengan kategori, penulis, dan tag.
- **Foto** - galeri dan berita foto.
- **Video** - kumpulan video berita.
- **Infografis** - informasi dalam bentuk visual.
- **e-Koran** - edisi koran digital.
- **Web Stories** - berita format cerita (AMP).
- **Live & Breaking News** - liputan langsung dan berita sela.

## Teknologi

| Bagian | Teknologi |
|--------|-----------|
| Frontend | Astro 7 (SSR) + React islands + Tailwind CSS |
| Backend / CMS | Laravel + React + Inertia, dengan fitur AI (`cms.beritana.com`) |
| Gambar | CDN Cloudflare R2 (`cdn.beritana.com`) + Image Resizing |
| Hosting | Cloudflare Workers |

## Fokus

SEO dan kecepatan jadi prioritas: struktur data (JSON-LD) lengkap, sitemap berita/video/
gambar, Open Graph, dan optimasi Core Web Vitals - agar berita mudah ditemukan di Google
News, Discover, dan mesin pencari.
